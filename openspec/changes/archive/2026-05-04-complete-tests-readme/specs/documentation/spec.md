## ADDED Requirements

### Requirement: README setup sections
El README DEBE contener secciones suficientes para levantar el proyecto en menos de 15 minutos.

#### Scenario: Setup local completo
- **WHEN** usuario sigue instrucciones del README
- **THEN** usuario puede ejecutar backend y frontend localmente

### Requirement: Credenciales documentadas
El README DEBE listar las cuentas de prueba disponibles.

#### Scenario: Credenciales listed
- **WHEN** usuario lee sección de credenciales del README
- **THEN** usuario conoce email y contraseña para cada rol

### Requirement: Comandos de test documentados
El README DEBE incluir comandos para ejecutar tests.

#### Scenario:Tests ejecutables
- **WHEN** usuario sigue instrucciones de test
- **THEN** usuario puede ejecutar tests del backend y frontend
