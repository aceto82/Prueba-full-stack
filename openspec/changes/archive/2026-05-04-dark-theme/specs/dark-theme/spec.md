## ADDED Requirements

### Requirement: User can toggle dark/light theme
The system SHALL provide a toggle to switch between dark and light themes.

#### Scenario: Toggle theme
- **WHEN** user clicks theme toggle
- **THEN** theme changes immediately

### Requirement: Theme preference persists
The system SHALL save theme preference in localStorage.

#### Scene: Returning user
- **WHEN** user returns to app
- **THEN** saved theme is applied
